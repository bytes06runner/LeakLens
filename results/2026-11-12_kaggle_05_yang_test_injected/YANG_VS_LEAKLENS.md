Split: **TEST** of the injected benchmark, 79 files. Yang analyser at commit `a7d038bf`, default command, Souffle route: built from source, tag 2.4.1 (fallback). LeakLens: static mode, findings of confidence medium or higher, run `2026-11-12_test_injected_leaklens_v1`.

A tool is right about a type in a file when it reports that type and the file has a labelled leak that accepts it; the hit counts for that label's primary type. This is looser than the protocol's line-overlap rule and is used here only because the Yang analyser reports the evaluation line, not the leaking line (EVAL_CHANGES.md #6).

**TEST: neither tool was tuned on these files. They are still files generated by this project's own mutation operators, of the same kinds LeakLens was developed against, so the comparison favours LeakLens; the human-labelled real notebooks are the fair test and are not done.**
